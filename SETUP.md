# Setup

1. Create the public GitHub profile repository `Nhan-Laptop/Nhan-Laptop`.
2. Upload all files and folders in this package to the repository root.
3. Create a fine-grained personal access token for GitHub API read access.
4. Add the token as repository secret `ACCESS_TOKEN`.
5. Open **Actions → Update GitHub Profile → Run workflow**.
6. Open `https://github.com/Nhan-Laptop`.

The SVG files are already customized for Nguyen Trong Nhan.
`GitHub Age` is calculated from the GitHub account creation date, so no birthday is required.
